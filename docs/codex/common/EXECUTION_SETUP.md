# 서버 Codex 실행 준비

문서판: 1.2-preparation. 이 문서는 준비 순서와 확인 항목이다. 설치·로그인·무인 실행이 완료됐다는 보고서가 아니다.

현재 실행 환경은 GitHub 공개 소스를 받은 문서 작업 환경이다. 실제 운영 서버의 CLI·계정·runtime·작업 경로를 직접 확인하지 않았다. 서버 GitHub 로그인과 현재 문서 작업 환경의 쓰기 인증은 서로 별개다.

## 활성화 전 확인

| 순서 | 확인 대상 | 완료 근거 |
|---|---|---|
| 1 | 서버 CLI와 worktree | CLI 버전·설정 지원 여부, 현재 계정, Git remote/branch/HEAD, 미커밋 변경 확인. 운영 원본과 개발 worktree를 구분 |
| 2 | ChatGPT 로그인 | D23에 따른 계정 로그인과 실제 이용권 확인. API 키나 인증 캐시를 다른 계정 또는 Git에 복사하지 않음 |
| 3 | 모델과 추론 | 주 에이전트와 필요한 각 역할의 `gpt-6.1-sol` / `xhigh` 사용 가능 여부 및 유효 설정 확인. 임의 모델 대체 없음 |
| 4 | 포함 사용량만 사용 | D24의 크레딧 차감·구매·API 전환 금지가 실제로 강제되는 방법을 확인. 불명확하면 무인 실행 보류 |
| 5 | 역할과 동시 실행 | 역할별 작업 경로·도구·권한 확인. 한 coordinator 아래 전문 역할 최대 2개, 총 3개. 여러 독립 세션으로 상한을 우회하지 않음 |
| 6 | 검사·독립 검토 | 프로젝트의 첫 작업 검사 계획을 test_agent가 작성하고 독립 reviewer가 확인. 구현 담당의 자체 확인을 독립 승인으로 세지 않음 |
| 7 | GitHub 경로 | 두 저장소의 쓰기 권한·PR·필수 검사·독립 검토·병합 권한 확인. 설정값만으로 자동 병합이 보장된다고 가정하지 않음 |
| 8 | 재개와 보고 | checkpoint·사용량 초기화 확인·문제 수정 횟수/시간·보류 작업·PR/상태 문서 보고 연결을 확인 |

모든 필요한 전제를 확인한 후 사용자에게 기능 개발 시작을 알린다. worker·scheduler·GitHub Actions·배포 자동화를 이 문서 작성만으로 활성화하지 않는다. 사용량 부족은 확인한 초기화까지 대기하며 문제 수정 횟수와 60분 상한은 세션 변경으로 초기화하지 않는다.

## 설정 예시의 한계

`../templates/config.toml.template`과 역할별 `.toml.template`은 비활성 예시다. `.codex` 또는 사용자 설정 경로에 설치하지 않았다. 최신 CLI에서 설정 지원 여부와 유효 설정을 확인한 뒤 적용할 대상이다.

`agents.max_concurrent_threads_per_session`은 주 스레드를 제외한 세션별 상한이다. 여러 primary 세션의 합산 상한을 대신하지 않는다. 단일 총괄과 공유 작업 상태가 필요하다. 역할 설명에 적은 경로는 실제 OS 접근 제한이 아니며 별도 권한 확인이 필요하다.

현재 확인한 공식 설정 자료는 개인 CLI에서 크레딧 차감 금지를 확실히 강제하는 제어를 증명하지 않는다. 포함 사용량 확인만으로 크레딧 미사용 조건이 충족됐다고 표시하지 않는다. 이 조건이 확인되기 전에는 에이전트 자동 대기·재개 실행기도 활성화하지 않는다.

## 공식 확인 자료

- [개발자 설정](https://learn.chatgpt.com/docs/developer-settings): 프로젝트 설정, 유효 설정과 strict-config 확인
- [인증](https://learn.chatgpt.com/docs/auth): ChatGPT 로그인 방식과 인증 저장소
- [에이전트 구성](https://learn.chatgpt.com/docs/agent-configuration/subagents): 세션별 동시 실행과 역할 설정
- [사용량과 요금](https://learn.chatgpt.com/docs/pricing): 포함 사용량 및 크레딧 동작

확인일: 2026-10-13. 실제 서버 버전과 계정에 적용되는 내용은 설치 단계에서 다시 대조한다. 자격 증명이나 개인 계정의 사용량 화면 원문은 공개 저장소에 남기지 않는다.

## 현재 준비 산출물

조회 도구와 native 실행 전제는 [READINESS.md](READINESS.md), 독립 reviewer의 역할과 필수 검사·관리 적용 명세는 [GITHUB_GATES.md](GITHUB_GATES.md)를 따른다. 구현 전 계획은 test_agent가 작성했고 독립 reviewer가 계획 v2 해시를 사전 검토했다. 검토 결과와 구현 검사는 프로젝트 PR에 별도 기록한다. 문서 준비와 fixture 성공만으로 서버·크레딧·병합 강제가 완료됐다고 표시하지 않는다.
