## 이후 보관 정책

1. 완료 후 성공·실패·시간 초과를 대표하는 소형 원본을 전체 5개 이내로 교체 보관한다. 잘된 결과만 골라 품질이 개선된 것처럼 기록하지 않는다.
2. 나머지는 실행 조건·버전·통과/실패·핵심 지표·한계를 요약하고 원본 보고서·중간 이미지·중복 JSON을 삭제한다.
3. 실행 중 또는 재개할 실험은 정리하지 않는다. 큰 실험은 각 도구의 출력 경로 옵션으로 프로젝트 밖 임시 작업 폴더에 저장하고, 분석 후 요약만 옮긴다. 실행 중 임시 공간까지 1 MB로 제한하는 정책은 아니다.
4. 삭제한 `report.json`의 재개와 전체 오프라인 재채점은 불가능하다. 필요하면 새 실험으로 다시 만든다. 일부 소형 canonical 원본만으로 전체 실험을 재현할 수는 없다.
5. 완료 결과 정리용 적용기는 첨부본과 해시가 같은 완료 결과만 삭제한다. 변경된 파일·활성 실험 잠금·예산 초과가 있으면 적용 전에 중단한다. 새 결과를 임의로 삭제하지 않는다.
6. 이 변경은 일회성 정리와 보관 정책이다. 테스트 실행기가 자동으로 결과를 지우도록 바꾸지는 않았다.

보고서 전체·baseline 사본·파생 PNG는 전달본에서 제거됐다. 남아 있는 요약과 대표 canonical은 기존 `--resume`/`--evaluate`의 완전한 입력이 아니다. 서버에 별도로 보존된 온전한 실행 폴더만 재개에 사용할 수 있다.

## 입력자료 정리

| 제거 파일 | bytes | 영향 |
|---|---:|---|
| ocr-quality/fonts/NanumGothic-Regular.ttf | 2,054,744 | 샘플 재생성 전에만 별도 복원 필요 |
| ocr-quality/preview.pdf | 284,444 | 개별 PDF로 확인 가능 |
| ocr-geometry/preview.pdf | 615,241 | 개별 PDF/JPEG로 확인 가능 |

위 3개에서 총 2,954,429 bytes를 제거했다. 필수 입력의 크기와 결과 예산 구분은 위 용량 절을 따른다.

## 유지하는 테스트 입력

- OCR 품질: 본문, 표, 2단, 텍스트/스캔 혼합 PDF 4개와 suite.json.
- 좌표 검사: 회전 PDF 3개, crop/원점 이동 PDF, 일반/EXIF JPEG, reference.png와 suite.json.
- OCR smoke 입력, 문서 품질 정답·영역·픽셀 검사 기준 JSON.
- OFL.txt: 생성된 PDF에 폰트 일부가 내장되어 있어 라이선스 안내를 유지한다.

이 입력들을 없애면 기존 파서/OCR/좌표 회귀 검사 및 해당 Docker 검사 stage가 실패할 수 있다. 전체 입력자료를 외부 보관하는 방식은 검사 전 복원 절차까지 함께 바꿔야 하므로 이번 변경에 포함하지 않는다. 없는 입력을 조용히 SKIP하거나 채점 기준을 약화시키지 않는다.

## 샘플 재생성이 필요한 경우

기존 개별 PDF·이미지를 사용하는 테스트에는 별도 폰트가 필요하지 않다. 생성 스크립트 generate_ocr_quality_fixtures.py / generate_ocr_geometry_fixtures.py는 개발용이며 폰트를 자동 다운로드하지 않는다.

1. fonts/NanumGothic-Regular.ttf를 기존 위치에 별도로 복원한다. 출처는 ocr-quality/README.md의 원래 Google Fonts 출처를 참고한다.
2. SHA-256이 suite.json의 값과 같은지 확인한다: `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31`.
3. 기록된 생성 의존성 버전에서 생성하고 페이지·정답·입력 해시를 검토한다. 새 출력의 바이트 일치를 가정하지 않으며, 실행 중인 실험의 입력은 교체하지 않는다.
4. 검토 후 별도 TTF와 생성된 preview.pdf는 다시 정리한다. 실제 입력과 suite.json은 함께 관리한다.

폰트를 복원하지 않은 상태에서는 생성 스크립트가 실패하는 것이 예상 동작이다. 이 변경은 운영 서비스나 기존 OCR 결과에 영향을 주지 않는다. 결과 정리 패치와 독립적으로 적용할 수 있다.

## 입력자료 정리 검증

TTF·중복 미리보기 제거 상태에서 OCR 회귀 37개와 좌표 검사 5개, 합계 42개가 통과했다. 추론 응답은 대역이며 실제 GPU OCR 품질 재시험은 아니다. 두 suite의 실제 입력 11개 해시가 그대로 유효하고, 운영 코드·실행 입력·정답·결과·라이선스의 바이트가 변경되지 않았음을 확인했다. 이번 문서 링크 수정을 포함한 fixtures 합계는 1,107,539 bytes다. 바이너리 입력과 suite 정답은 바꾸지 않았다.
