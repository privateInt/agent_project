지식 목록

사용할 지식을 선택해 검색하거나, 자료를 바꾸어 새 버전을 만드세요.

선택한 지식

완료된 버전에서 ‘검색에 사용’을 누르면 기본 검색 버전으로 지정됩니다.

지식 만들기

자료와 모델을 선택하면 청크 생성부터 색인까지 순서대로 진행합니다.

  1. 1. 자료 선택
  2. 2. 처리 설정
  3. 3. 확인·시작

데이터 플랫폼에서 정리한 결과를 사용합니다. 자료의 ‘추가’를 눌러 사용할 정리 버전을 고르세요.

선택한 자료 0/20

임베딩 모델은 자료를 검색용 벡터로 변환합니다. 모델 플랫폼에서 배포된 모델을 선택하세요.

청크 크기 조정

기본값으로 시작할 수 있습니다. 큰 표는 행 단위로, 코드는 줄 단위로 나눕니다. 원본 구조를 확인할 수 없으면 이유를 표시합니다.

청크 미리보기 (선택)

색인 전에 나누어진 내용을 확인할 수 있습니다. 이 버튼은 청크만 생성합니다.

고급 색인 설정 · HNSW

비우면 16 / 128을 사용합니다. 값을 높이면 메모리 사용량이나 색인 시간이 늘어날 수 있습니다. 새 버전에서 청크 임베딩도 다시 수행합니다.

이전 버전과 연결 (선택)

변경 이력을 연결합니다. 처리 설정은 이번에 선택한 값을 사용합니다.

시작 전에 확인하세요

‘생성 시작’을 누르면 모델을 사용해 자료를 색인합니다. 완료 후 목록에서 ‘검색에 사용’을 눌러 기본 검색 버전을 지정하세요.

지식 검색

지식을 선택하고 질문을 입력하세요. 관련된 원문과 출처를 보여드립니다.

검색 버전 변경

기본 검색 버전을 자동으로 선택합니다. 보존된 다른 버전도 선택할 수 있습니다.

검색 후보를 질문과 비교해 다시 정렬합니다. 모델의 입력 길이를 초과하면 이유를 표시합니다.

검색 옵션

원본 자료와 정리 품질은 데이터 플랫폼에서 관리합니다. 여기에서는 정리된 내용을 나누고 색인하여 검색합니다.
